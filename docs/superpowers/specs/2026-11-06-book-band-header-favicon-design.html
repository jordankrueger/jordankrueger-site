Verdict

Four small changes to jordankrueger.com, built as three separate pieces by three Codex workers running at the same time: the picture book gets a sun-colored band on the homepage below "Two practices I run" (plus an entry under Movement work); the header's Projects link becomes a menu that also holds AI and Tools; CampaignHelp gets a small arrow showing it leaves the site; and the favicon becomes the sun-and-leaf mark already beside your name. No new pages, no new packages. Each piece ships as its own pull request and is checked on the live site after it merges.

Slice 2 — Projects menu and CampaignHelp arrow

Reuses the header's links, styles and mobile menuAdds a menu button, a small card of six links, an arrow icon

Opens on click or hover, closes on Escape, clicking elsewhere or tabbing away; never closes under a keyboard user. Works with JavaScript off on desktop. The phone menu scrolls so nothing gets cut off on short screens.

Testing

Each slice comes with a browser check that clicks through the real page and fails loudly if anything is off: link order and addresses, menu open and close in every way a person would use it, the book band's position and buttons, and the icon files' sizes and types. The menu check is proven to work by breaking the Escape key on purpose and watching it fail. All three run against the preview build of each pull request, then against jordankrueger.com after merge. The header check stays in the repo so any future header change runs it too.

Reviews: Claude reads every diff, then a Codex adversarial review; the spec itself was reviewed by GPT-6.1-Sol (approved on round three).
